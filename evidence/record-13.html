研究方向：出口別の点群削減評価

  • 作成日: 2026-10-04
  • 対象: 卒業研究「建築点群リダクション後の品質評価」
  • 位置づけ: 中間試問後の方針具体化と、次の実験の判断記録

結論

解決したい困りごとは、点群データが重すぎて処理が進まないことである。必要な形や属性を残し、手元のPCで最後まで処理できる量へ減らすことを目指す。止まるソフト・工程・実ファイルと、メモリ／計算／入出力のどれが主因かは未特定。

CSCという一手法の優位性の証明を目的にせず、用途に必要な情報・合格条件から、間引きの設定を選びやすくすることを解決の手段に置く。用途調査や設定ガイドの存在だけを、処理停止の解決とみなさない。

2026-10-04の追加調査で、一次資料19件を8用途系統／11選択肢に整理した。用途別の調査と、複数用途を選べる設定ガイド（公開版未収録）を参照する。ガイドは試行候補の生成であり、全用途の最適値や実用精度を検証した成果ではない。

現在の結果は、同じCSCでも評価軸によって結論が変わることを示している。

  • ESR（長尺構造点保持率）: CSCが均一間引きより大きく改善
  • MCR（少数クラス点保持率）: ほぼ同等
  • BPR（部材境界点保持率）: CSCは均一間引きを上回らない
  • 幾何忠実度: 全43タイルのD1誤差で、全削減率・全タイルにおいてCSCが不利

卒業研究の主な問いは「用途に必要な情報を守りながら、手元のPCで処理できる量へ点群を減らし、その設定を容易に選ぶには、どんな要求・評価・選択手順が必要か」である。

成功は、処理完了・読込と間引きを含む全工程時間・最大メモリ・用途の品質・設定の容易さで測る。既存実験は最大8万点の範囲ごとの比較で、巨大な元ファイルの処理完了は未確認。Houdini・環境・費用の調査（公開版未収録）は実装手段の検討であり、Houdiniの動作や全規模の処理成功を実証したものではない。

その中の一つの検証課題として、次を扱う。

MCR・BPR・ESRのような軽量な保持率は、削減後の独立な品質や出口性能をどこまで予測でき、どの条件で外れるか。

前回からの研究上の変化

前回も「利用目的・評価指標・削減条件の対応」を最終成果としていた。中間試問後に変わったのは、方向そのものよりも実験の解像度である。

  1. 「利用目的」を、表示、セグメンテーション、シミュレーション、メッシュ化などの出口に分けた。
  2. 出口ごとに必要な情報と最終性能を分けた。
  3. MCR・BPR・ESRを最終性能ではなく、出口性能を予測する候補指標として位置づけ直した。
  4. BPRの削減率別再分析と、独立な幾何忠実度の全43タイル評価を実行した。
  5. 同一の削減点群からMCR・BPR・ESRも再計算し、幾何誤差差との相関を調べた。

現在までの証拠

削減率スイープ

ArCHの既存結果では、50・70・90%削減のすべてで次の傾向が出ている。

指標 CSCと均一間引きの比較 現時点の解釈
MCR 差は約0 CSCは少数部材を特別に保護していない
BPR CSCがわずかに低い CSCは部材境界の保持に最適化されていない
ESR CSCが大きく高い CSCは長尺構造点を優先して残す

この結果だけでも「何を残したいかによって、同じ手法の評価が変わる」ことを示せる。ただし、三つとも元点群の特定点が残った割合であり、下流性能そのものではない。

幾何忠実度の全43タイル評価

ArCH 5シーン・全43タイルで、元点群から削減後点群への距離を測った。各タイル・削減率で、均一間引きとCSCの削減後点数を一致させた。

目標削減率 D1相対差平均 D1でCSC良 / 悪 D2相対差平均 D2でCSC良 / 悪
50% +1.89% 0 / 43 +1.49% 7 / 36
70% +2.71% 0 / 43 +4.69% 3 / 40
90% +3.66% 0 / 43 +5.17% 2 / 41

誤差は小さいほど良い。D1では全条件・全43タイルでCSCの誤差が大きく、D2でもCSCが不利なタイルが大半だった。ただし43タイルは5シーン内の範囲であり、独立した43建物ではない。従来のタイル単位の小さなp値を建物一般への推論には使わない。5シーンを単位にしたD1の増加は+1.88/+2.71/+3.71%、両側exact Wilcoxonは各率p=0.0625だった。ESRの改善は、このデータ内でも点群全体の被覆誤差改善を保証しない。

旧D2は元点群の計算済み法線を継承している。追加で削減後XYZだけから法線を推定し直した258条件では、5シーン等重みのD2増加は+0.94/+2.64/+4.90%で、全5シーン・全率でCSCの平均誤差が大きかった。実際のメッシュ再構成の評価ではない。

保持率と幾何誤差差の関係

同じ258行から CSC − 均一間引き の差を作り、Spearman順位相関を調べた。

  • MCR・BPR: 幾何誤差差との明確な相関は未確認
  • ESRとD1: 70%で ρ = -0.406, p = 0.0069、90%で ρ = -0.470, p = 0.0015
  • ESRとD2: 70%で ρ = -0.366, p = 0.0159、90%で ρ = -0.515, p = 0.0004

負の相関は、今回のデータ内でESR改善が大きいタイルほどCSCの幾何誤差の悪化幅が小さい傾向を示す。ただしD1の絶対結果は全43タイルでCSCが不利である。シーン内の非独立性・複数比較・未使用データでの検証欠如があるため、これらのタイル相関とp値は探索用に限定し、予測力の証明とはしない。

推奨する研究設計

実験1：幾何忠実度の全面評価（完了）

既存データとCPUだけで実行し、ESRとの循環を避けた独立評価を完了した。

  • データ: ArCHの全43タイル
  • 手法: 均一ボクセル間引き、CSC
  • 削減率: 50%、70%、90%
  • 指標:
  • 元点→削減点のRMS距離
  • 元点→削減点の95パーセンタイル距離
  • 元点→最近傍削減点の法線面へのRMS距離
  • 同95パーセンタイル距離
  • 正規化: タイルのバウンディングボックス対角長
  • 比較: タイル単位の対応差を記述し、シーン内で集約した5シーンの差も確認する。従来のタイル単位p値は一般化の根拠にしない
  • 追加分析: ESR差と幾何誤差差の相関（完了）

判定結果

  • CSCの誤差が大きい結果となった。
  • ESRの成功と幾何忠実度の失敗を、proxyの適用限界として研究成果にする。
  • 同時に、ESR改善量と誤差悪化幅には70・90%削減で負の相関があるため、完全に無関係とは扱わない。

事前にどの結果でも研究上の意味が残る設計とし、今回の結果をproxyの適用限界として解釈した。

実験2：セグメンテーションへの接続（CPU簡易評価を実施）

BPRを最終指標にせず、実際の境界認識やクラス別IoUとの関係を調べる。

ArCH用RandLA-Netのコードはあるが、利用可能なチェックポイントはSemanticKITTI用19クラスである。ArCH用10クラスの完成した学習済みモデルは確認できていない。そこで既存の幾何特徴・削減コードと、導入済みscikit-learnのRandom Forestを組み合わせて、CPUで再現できる簡易比較を実施した。

比較の条件は次の通り。

  1. 5シーンのうち4シーンの元点群で学習し、残り1シーンで評価する比較を5回行う。
  2. 各回の同一分類器を元点群・均一間引き・CSCの50/70/90%削減へ固定して適用する。
  3. 特徴は各入力のXYZだけから再計算する。正解、RGB、保存済み法線は入力にしない。
  4. 減らした点の予測を最近傍の元の点へ戻し、全方法を同じ正解点で採点する。
  5. シーンごとに混同行列を合算してから、正解に存在するクラスの平均IoUを計算し、最後に5シーンを等重みで平均する。
  6. 全43範囲・301入力条件を処理。全点Undefined10の2範囲を除く、41範囲・287条件に分類成績がある。

均一/CSCの平均IoUは50%削減で24.39/24.37%、70%で24.12/23.94%、90%で20.32/20.17%。差は-0.02/-0.18/-0.15ポイントと小さく、少数部材の平均IoUと正解境界点上の部位正答率でも一貫した改善は確認できなかった。同等性や実用差を証明した結果ではない。

元点群は22.71%であり、50・70%削減では平均成績がやや高い。近傍範囲の変化や最近傍戻しも含む固定評価器の結果なので、「削減は必ず分類性能を落とす」とは言わない。絶対性能は低く、この分類器で5シーンを比較した範囲に限定する。BPRと境目正答、MCRと少数部材IoUのシーン単位相関も算出したが、5点のみの探索で、予測力は未検証である。

分類器の乱数だけを0/1/2に変えた感度確認も実施し、元の分割・訓練サンプル・入力点・特徴は固定した。入力サンプルの乱数や別方式の頑健性まで確認したものではない。

実験3：実測建築への外部確認

浄土寺浄土堂とHoudiniは破棄しない。評価指標の有効範囲をArCHで固めた後、実測建築で同じ傾向が見えるかを確認する外部検証として使う。

Houdiniは研究対象ではなく、同条件の削減点群を生成・可視化する実験環境とする。

その前段として、手元の別データ3DITAを全8寺院・32範囲・192条件で評価した。CSCを再調整せず使用し、全率・全32範囲で点→点誤差が大きくなった。寺院を等重みで平均した増加は+1.59/+2.45/+2.53%。細長い形の点の保持率は、元から対象点がない3範囲を除く29範囲で集約し、全8寺院で改善した。除外3範囲は元の点群から対象点0を再確認しており、未定義値を0に置き換えてはいない。対象数は cross_dataset_geometry_3dita_coverage.json に記録した。ESRと全体の距離誤差を区別する必要はこの別データでも見られた。ただし、日本建築の実測、分類、メッシュ再構成、シミュレーションを検証したものではない。

形の復元 元点群との距離は測定済み。実際のメッシュ復元は未実施 法線・復元方式を固定し、実際の面と開口を評価する

位置合わせ 文献調査と多段階設定を整理 粗合わせと密な精密化の総時間・独立基準誤差を測る
計測・変化検出 文献調査。計算地点だけ減らす別ルートを整理 元の不確実性・独立基準・検出限界を確認する

記録保存 原本と用途別コピーを分ける運用案 取得・加工履歴と再利用性を確認する

研究全体を二用途に限定しない。広い用途調査と共通の設定支援を研究の中心にし、既存の距離・分類実験を代表的な証拠として使う。追加の代表実験は、用途間の要求の違い・衝突を示せる組合せと利用条件で選ぶ。条件が揃わない解析を検証済みとはしないが、一律に対象外と固定もしない。

複数用途を共有するコピーでは、各用途の必須条件をすべて満たす候補を残す。両立しなければ用途別のコピーに分ける。品質に加え、設定時間・試行回数・誤設定を測り、「設定が容易になった」ことも今後の検証対象にする。

先行研究との接続

点群サンプリングは、後工程を考慮しない方法では下流性能が低下しうるため、タスクに合わせて学習・適応する研究が進んでいる。

  • SampleNet（CVPR 2020）は、従来サンプリングが下流タスクを考慮しない問題を示し、分類・再構成・位置合わせでタスク依存のサンプリングを評価した。
  • LTA-PCS（CVPR 2024）は、タスク固有サンプリングとタスク非依存サンプリングの間を課題として扱い、複数の下流タスクで評価した。
  • MICAS（CVPR 2025）は、再構成、ノイズ除去、位置合わせ、セグメンテーションで必要なサンプリングが異なることを前提に、タスク適応型の仕組みを提案している。
  • 歴史建築点群のEEI-Net（ISPRS 2023）は、歴史建築の部材セグメンテーションで境界情報を明示的に扱っている。BPRを境界側の候補指標として検証する根拠になる。
  • SUM Parts（CVPR 2025）は、点数だけでなくサンプリング分布がセグメンテーション性能に影響することを比較している。

これらは本研究の結果を直接証明するものではない。ただし、「一つのサンプリングが全用途で最適とは限らず、下流タスクで評価する必要がある」という研究方向を支持する。

次回ゼミ後の完成条件

幾何忠実度の全43タイル評価、対応検定、保持率との相関分析は完了した。次は以下を進める。

  1. CPU簡易分類器による同一評価器比較、BPR/MCRとの対応分析、乱数感度確認は実施した。
  2. 実測建築の入力は、XYZ・単位・取得条件・利用権限を確認した点群が必要。BPR・分類成績を測るには、人が付けた部位の正解も必要。今回確認した両研究リポジトリ内に、浄土寺の評価用点群は見つからなかった。
  3. MacのPyTorchはCUDA不可・MPS可。既存RandLA-Netの学習コードはCUDAまたはCPUで、MPS利用を確認していない。完成したArCHモデルがないため、未学習・別データ用重みを本評価として使わない。
  4. 出口ごとの許容品質低下は、今回の結果から勝手に決めない。実際の利用者・先生との判断事項として残す。

最新の条件・数値・残作業は ゼミ進捗（公開版未収録）、入力準備の仕様は external_validation_protocol_2026-10-05.json を参照する。
