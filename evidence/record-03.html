2.1 H1：削減手法は非削減 (=1.0) を有意に下回るか

各主指標について 1.0 を対照群とした one-sample Wilcoxon signed-rank（alternative='less'）。 deficit = 1 − 平均値、95% CI は bootstrap (n=5000)。Bonferroni 補正後 α = 0.05/6 = 0.0083。

uniform_voxel ESR 43 0.4525 +0.5475 [0.494, 0.599] 8.22e-09 ✅

3. 結論：H1 / H3 の判定

E案 §6 / §15 で定義した H1〜H3 への暫定回答：

仮説 結果 備考
H1（均一は非削減を有意に下回る） ✅ 支持 6 検定すべてで p < 1e-7（Bonferroni 後）。uniform で MCR 73.2%・BPR 78.4%・ESR 54.8% を喪失。csc は ESR の deficit が 35.3% に縮小
H3-MCR（CSCが均一を上回る） 不支持 Δ≈0、p=0.29、勝率 52%。CSC は label-free のため少数クラス保存には寄与しない
H3-BPR（CSCが均一を上回る） 不支持 Δ がむしろ負（−0.0013）、勝率 39%。境界保存にも寄与しない
H3-ESR（CSCが均一を上回る） ✅ 強く支持 Δ=+0.1945、p=8.2e-09、勝率 97.67%。CSC は長尺/構造的な点を強く優先保持する

4. 解釈

4.1 ESR で顕著な勝利が出た理由

CSC スコアは linearity / planarity / scattering / verticality といった 局所幾何的に「構造的」な点を高く評価する ように設計されている。これらは ESR の定義（固有値ベースの長尺性）とほぼ同じ計算経路を共有しているため、ESR で大幅な改善が出るのは半ば自明である。

これは CSC の 構成的妥当性の確認としては意味があるが、独立な「外部評価」とは言い切れない。次フェーズでは CSC で使う記述子を ESR の定義から完全に分離するか、ESR を別の保持指標で置き換えるかを検討する必要がある。

4.2 MCR が改善しなかった理由

CSC スコアは ラベルを一切参照しない（§7.1）。少数クラス（arch / column / molding / door-window）の点が必ずしも「構造的」な特徴を持つとは限らない（壁の角や床の縁にも同様の特徴が出る）。

→ MCR を改善するには、CSC の重み $w_k$ を train 上で少数クラス保持率を最大化する方向にグリッドサーチ する必要がある（§12 批判2 の対応として計画書に既述）。これは標準構成 (§13.2) で着手すべき次のステップ。

4.3 BPR が逆に悪化した理由

CSC スコアが高い点（強い構造性を持つ点）は voxel 内で「平面の内部」「線の中心」に近く、境界からは離れている傾向がある。一方 boundary continuity の派生量（boundary_discontinuity）も使ってはいるが、寄与が小さい。

→ BPR を改善するには、CSC の "planar_edge" 重みを上げるか、s_geo の boundary 寄与を強める必要がある。

0.0 (pure CSC) 0.2671 0.2151 0.6437
0.5 0.2688 0.2146 0.6470

→ α の影響は軽微。CSC と s_geo は MCR/BPR/ESR で大差なし。論文では α=0.5 を採用する正当化は弱い → α=0 (pure CSC) でも結論は同じになる。

5b.4 Shuffled CSC（grid 最良 scales を 20 回ランダム並べ替え）

指標 grid mean shuffle 平均 ±std grid > shuffle 数
MCR 0.2715 0.2687 ±0.0003 20/20 ✅

→ 構造別重み設計は MCR/BPR で明確な信号を持つ（どのランダム順列にも勝つ）。 → ただし grid は MCR 最適化を選んだ結果、ESR で構造設計の良い面を打ち消してしまっている。

5b.5 統合的考察

  1. MCR と ESR は本質的に trade-off: grid (MCR 最適化) は ESR を 0.60 → 0.48 まで落とす
  2. 論文の主張は ESR ベースで組み立てるのが安全: csc_default で p < 1e-8 が出ているのが最も再現性高い
  3. MCR は意味のある向上が可能だが微弱: label-free のままでは構造的に上限がある
  4. 次の根本対応: Pareto front 探索 or label-aware 重み学習 or 別の最適化目的

7. 卒論執筆への含意

ポジティブ:

  • CSC が ESR で 強く有意（p < 1e-8）に勝つという、検証可能で再現可能な事実が得られた
  • 「構造的記述子に基づく適応的リダクションが、長尺な構造を統計的に有意に保持する」と書ける

慎重に書くべき点:

  • ESR と CSC の記述子が一部重複している（fairness 問題）→ 論文では別指標との独立性を補強する必要がある
  • MCR / BPR では H3 が不支持 → 単純 CSC は label-aware にしないと少数クラス保護にならない。これは E案 §15 の主張をそのままでは支持できないことを意味する
  • → 次フェーズで 重み学習 + 追加ベースライン を入れて再検証することが必須
